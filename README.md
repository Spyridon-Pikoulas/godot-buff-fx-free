# Buff FX Free

**7 animated buff, power-up and loot effects as PNG sprite sheets, free, for any engine.** Each
comes in three sets: 256 px and 128 px HD, and pixel art drawn at 64 px, not shrunk.

### Want more?

**[Buff FX](https://heyheythere.itch.io/buff-fx)** has 102: loot beams in all 6 rarity colours,
auras, stuns, stat icons, loot drops and rarity frames, and every effect in each colour. It adds
debuffs, level ups, glows and shines too, with the same sheets and player.

### What's inside

- A gold **buff**, **pickup** and **power up**, a green **heal**, a blue **shield**, and a white
  **loot beam** and **sparkle**. All but the heal and pickup loop seamlessly.
- Transparent PNG sheets, 8 frames a row, plus an `effects.json` with every frame size, frame
  count, fps, loop and anchor, and a GIF preview of each.
- **Godot 4 player included:** `BuffFX.spawn(hero, "gold_buff", hero.position)`. Import steps
  for Unity and GameMaker in the README.

### Compatibility

- **Any engine** that plays sprite sheets: Unity, GameMaker, Godot, Defold, Construct, Phaser,
  LÖVE, MonoGame.
- The Godot player: Godot **4.3 to 4.7**, tested on both ends and on every renderer.
